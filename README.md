# Python Lab

Este repositório reúne experimentos, estudos e pequenos projetos
desenvolvidos durante meu aprendizado de Python.

Os projetos têm como objetivo praticar programação, análise de dados
e exploração de diferentes bibliotecas e ferramentas do ecossistema Python.

## Projetos

- Simulação de sinais de EEG (ondas Delta, Alpha e Beta) e adição de ruídos
- Análise de preços de gasolina e etanol (2004–2021)
- Outros experimentos e estudos em Python

## Tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
