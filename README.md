# Python Lab

Este repositório reúne experimentos, estudos e pequenos projetos desenvolvidos durante meu aprendizado de Python.

Os projetos têm como objetivo praticar programação, análise de dados, processamento de sinais, visão computacional e exploração de diferentes bibliotecas e ferramentas do ecossistema Python.

## Projetos

- **Simulação de sinais de EEG**
  - Simulação de ondas Delta, Alpha e Beta
  - Combinação de sinais
  - Adição de ruído de 60 Hz
  - Visualização e análise dos sinais

- **Análise de preços de combustíveis**
  - Análise dos preços de gasolina e etanol entre 2004 e 2021
  - Manipulação de dados com Pandas
  - Visualização dos resultados

- **Inspeção automatizada de peças com visão computacional**
  - Projeto desenvolvido em parceria com a Universidad de Monterrey, México
  - Utilização de OpenCV para processamento e análise de imagens
  - Detecção de componentes de uma peça por meio de contornos e características geométricas
  - Binarização e operações morfológicas
  - Sistema de contagem e identificação de possíveis falhas
  - Registro dos resultados utilizando Pandas

## Tecnologias
